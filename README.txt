Seba Medical Hall Website Project
=================================

Project type:
- Static website
- HTML, CSS, JavaScript only
- No API required
- Bangla and English language switch included
- Separate About page included
- Smooth transitions and scroll reveal animations included

Pages:
1. index.html
   Main pharmacy page.
   Sections:
   - Hero
   - Services
   - Doctor preview
   - Contact and Google Map button
   - Disclaimer

2. about.html
   Separate page for Dr. Mohammad Mosharraf Hossain.
   Sections:
   - Profile
   - Devidwar Medical College information
   - Village doctor/service history
   - Freedom Fighter Commander information
   - Address and Google Map button

Important location:
Village Jhinaiya, No. 3 Rosulpur Union, Devidwar Police Station, Cumilla District 3530, Bangladesh.

Google Map link:
https://maps.app.goo.gl/da37eKfEbNyJsp4y8

How to run:
1. Unzip this folder.
2. Open index.html in your browser.
3. Or open the folder in VS Code and use Live Server.

How to edit text:
- Open js/main.js.
- Edit the Bangla and English text inside the translations object.

How to change images:
- Replace assets/doctor-mosharraf-hossain.png with a new doctor image.
- Replace assets/freedom-fighter-logo.png with another logo if needed.
- Keep the same file names to avoid changing the HTML.

Note:
The map icon is a custom map-pin style icon with Google Maps-style colors. It is not an official Google asset.
